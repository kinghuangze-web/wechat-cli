# 把 Grok Bot 接进微信：查群聊、找重点、收日报

微信群积了几百条消息，你可以直接问：“这个群今天聊了什么？”
想找一条消息，也可以让助手去查，不用自己翻半天。
这篇带你把 Grok Bot 接进微信，让它读取电脑上的群聊记录，再把整理好的结果发回微信。

安装时请 Codex 帮一次忙。接好以后，日常就在微信里发任务，由 Grok Bot 安排查询和整理。

## 开始前，准备好这些

- 一台 Windows 电脑，微信已经登录，能看到要查询的群和聊天记录。
- 能正常使用的 Grok Bot，作为之后的微信助手。
- 电脑上能正常对话的 Codex，负责安装和处理部署问题。
- 手机微信，以及一个准备先试用的群。

本文从这两个 AI 工具已经能正常使用开始。先记下测试群在微信里显示的完整名字，后面只需要替换群名。

如果需要的旧消息只在手机里，先通过微信自带功能把记录迁到电脑。助手只能查到电脑上已有的部分。

## 第一步：让 Codex 把电脑准备好

打开 Codex，新建一个普通聊天。把下面整段复制过去，**只修改群名**：

```text
请帮我部署 Grok Bot 微信助手需要的群聊读取功能。
你负责电脑上的安装和排障；以后由 Grok Bot 接收我的任务、调用查询和整理结果。

我先试用的群叫：这里换成你的群名。

请阅读配套技术说明，在我这台 Windows 电脑上完成部署：
https://github.com/kinghuangze-web/wechat-cli/blob/main/docs/technical/README.md

如果已有能用的安装，直接复用。
只读取我指定的群，不发微信消息，不上传聊天记录。
需要我登录或做其他操作时，一次告诉我一个动作。
技术问题请你处理，不要让我手动输入命令或修改代码。

完成后，实际读取这个群的一条消息，确认已经能用。
然后给我一段“交给 Grok Bot 的接入说明”，写清楚它怎样调用现有安装。
说明里不要包含密钥或聊天正文，我会把它私下复制给 Grok Bot。
```

按 Codex 的提示完成登录等操作。它如果找到多个同名群，核对后选择正确的那个。

**等它确认“指定群已经读取成功”，并给出接入说明，再继续。** 只说“安装完成”还不够。

## 第二步：把接入说明交给 Grok Bot

打开 Grok Bot，新建一个聊天。把 Codex 刚给你的接入说明粘贴进去，再一起发送下面这段话：

```text
我想让你成为我的微信助手。
以后我在微信发任务，你负责安排查询群聊、整理内容，再把结果发回微信。

上面是 Codex 已经准备好的电脑接入说明。
请先阅读这份配套说明，完成微信连接和本机调用：
https://github.com/kinghuangze-web/wechat-cli/blob/main/docs/technical/GROK_WECHAT.md

已有安装直接复用，不要让我从头再装。
先确认你能否通过已有工具访问保存微信记录的那台电脑。
如果缺少连接条件，说清楚需要我打开哪个入口，不要把没接通说成接通。

安装和技术问题由你处理。需要我操作时，一次只说一个动作。
需要密钥时，请使用专门的私密输入位置，不要让我在聊天里发明文。
只处理我绑定的微信账号，按我指定的群和时间查询，不上传聊天记录。

接好后，先让我在微信发“你好”，收到回复后再测试群聊查询。
最后让我在微信提出日报请求，直到我确实收到能打开看清的日报图片。
```

接入说明是给两个助手衔接用的，你不用读懂。不要把自己的这段说明发进公开评论区或放进公开仓库。

## 第三步：按提示扫码，把助手放进微信

接下来需要你动手的，主要是打开设置、填写连接信息和扫码。

1. Grok Bot 让你打开哪个面板，就按提示打开。找不到时，把当前页面截图给它，让它指出具体位置。
2. 如果它要求复制两项连接信息，按它指出的位置分别复制，再填进专门的私密输入框。
3. 它发来绑定二维码后，用手机微信扫码，并在手机上点确认。二维码过期，就让它重新生成。
4. 绑定后，在微信中出现的助手对话里，**主动发一句“你好”**。
5. 等它真的在微信里回复你。

先发这句“你好”很重要。不要只看 Grok Bot 说“绑定完成”，要亲自在微信里收到一条回复。

这条路线需要你的 Grok Bot 和微信账号具备相应入口。如果助手确认当前版本没有所需能力，先停在这一步，让它说明缺什么；不要照着不存在的按钮来回找。

## 第四步：确认它真的能查到群聊

现在直接在微信的助手对话里发下面这句话，把群名换成自己的：

> 请查一下“这里换成你的群名”最近的一条消息，告诉我大概在聊什么，不用贴出原文。

核对它返回的群名和内容，确认是你指定的群。

**能在微信聊天，还要能查到指定群，才算这一步完成。** 如果它说只能看到你直接发给它的消息，把这句话发回 Grok Bot：

> 微信回复已经通了，但电脑上的群聊还没接上。请继续按 Codex 给的接入说明处理，直到能查询我指定的群。

如果它需要 Codex 补充信息，把问题复制给原来的 Codex 聊天，再将回答交回来即可。

## 第五步：做出第一份图片日报

继续在微信里发送下面这段，仍然只需要改群名：

```text
做一份“这里换成你的群名”今天的群聊日报，只要图片。

按北京时间，从今天零点整理到现在。
先读完这个时间范围的本地记录，再按话题整理重点。
开头写日期、统计截止时间和实际读到的消息条数。
保留有用结论、不同观点和待跟进事项。
猜测或玩笑要说清楚；没看过的图片、视频和语音不要猜内容。

做成手机上放大后能看清的图片，直接发回这个微信对话。
内容太长就分成几张，不要把字缩得很小。
```

拿到图片后，打开看看：群对不对、时间对不对、字看不看得清。

不满意就继续在微信里改：

> 字太小了，请分成两张图，把正文放大。

> 以后日报重点放在工具和方法上，生活闲聊简短带过。

> 这张图我要转发，请隐藏真实群名，把姓名换成“成员 A、成员 B”，再检查有没有私人信息。

第一次调到满意后，告诉 Grok Bot：

> 把这次日报的格式保存成我的默认要求。以后我说“出日报”，就按这个样式做，默认只发图片。

到这里，你已经可以从微信发任务，再从微信收结果了。

## 以后可以直接这样用

**没时间爬楼：**

> “学习交流群”今天有什么值得看的？给我五条重点。

**想找以前说过的话：**

> 帮我查“学习交流群”最近七天关于视频剪辑工具的讨论，整理大家推荐了什么、为什么推荐。

**想看一段时间的讨论：**

> 整理“学习交流群”昨天晚上七点到现在的聊天，告诉我有哪些结论还没说清楚。

**想做周报：**

> 做一份“学习交流群”最近七天的图片周报，按话题合并，别把每天相同的讨论重复写。

说清楚**哪个群、什么时间、要什么结果**，比只说“整理一下”更容易拿到你想要的东西。

## 可选：让它把聊天记录备份到自己的 GitHub

只想用微信助手，可以跳过这一节。想长期保存原始记录，再给 Grok Bot 发下面这段，并改好群名和时间：

```text
请在我自己的 GitHub 账号下创建一个私有仓库，用来备份聊天记录。

这次只备份“这里换成群名”，时间范围是“这里换成日期或起止时间”。
我同意把这次指定范围的记录上传到这个私有仓库。
需要我登录时，请指引我在登录页面完成。

上传前核对群名、时间和消息是否完整。
不要上传微信密钥、电脑配置或其他群的记录。
完成后重新打开仓库检查，再给我能查看文件的链接。
```

点开它给的链接，登录自己的 GitHub，确认仓库标着“Private”，文件的日期和群名也正确。

这一步会把指定记录保存到 GitHub。手动备份一次，不代表以后每天自动备份；需要定时做时，再单独说清楚。

## 遇到这些问题，直接发这句话

**微信发了消息，助手没反应：**

去 Grok Bot 原来的聊天里说：

> 我的微信消息没有回复，请检查连接是否还在运行。恢复后让我在微信发“你好”，确认收到回复再告诉我完成。

**助手说发了，但微信没收到：**

先在微信的助手对话里发一句“请重发”，再告诉 Grok Bot：

> 我刚在微信发了新消息，请重新发送。以我在微信实际收到为准。

**找错群了：**

> 我说的是完整群名“××”，请重新确认，不要按之前猜的群继续做。

**日报漏了很多内容：**

> 请检查是否只读了最近一部分，核对完整时间范围。电脑上没有的记录直接说明，不要补写。

**图片发不出来，或者字模糊：**

> 请拆成几张清晰图片，逐张发送。我需要能打开看到的图片，不是“图片已经做好”的通知。

**电脑上的安装出了问题：**

把 Grok Bot 提供的具体问题发给原来的 Codex 聊天，让 Codex 修复。修好后，回到微信再试一次指定群查询。

## 用之前知道这两件事就够了

要读取群聊，保存记录的电脑需要开着，并且能被助手访问。手机上的聊天入口不会自动补齐电脑没有的历史记录。

交给助手分析的记录，可能会由你使用的 AI 服务处理。先从一个群、一个明确时间段开始；准备转发的日报，自己看过再分享。
